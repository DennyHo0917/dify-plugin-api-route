# Privacy Policy

This plugin sends requests from your Dify instance to the fixed HTTPS endpoint `https://global.api-route.com/v1`. Each request sends the selected model ID, prompt messages, model parameters, optional tool definitions, and the API Route key as a Bearer token.

The plugin does not store user content, credentials, or usage records, and does not send telemetry to a separate service. API Route processes requests and may retain usage information as described in its [privacy policy](https://www.api-route.com/privacy-policy). Requests may be routed to upstream model providers as described there.

Source code: https://github.com/DennyHo0917/dify-plugin-api-route.
